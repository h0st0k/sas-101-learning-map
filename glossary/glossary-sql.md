# Глоссарий: SQL и базы данных

## А
- **Агрегатная функция** — функция, возвращающая одно значение из группы строк (COUNT, SUM, AVG, MAX, MIN).

## Г
- **GROUP BY** — оператор группировки строк по значениям столбца.

## Д
- **DDL** — язык определения данных (CREATE, ALTER, DROP).

## Ж
- **JOIN** — оператор соединения двух таблиц по условию.

## И
- **INNER JOIN** — соединение, возвращающее только совпадающие строки из обеих таблиц.
- **INDEX** — индекс, ускоряющий поиск данных.

## К
- **Ключ** — поле, идентифицирующее запись.
- **Первичный ключ (PK)** — уникальный идентификатор записи.
- **Внешний ключ (FK)** — ссылка на первичный ключ другой таблицы.

## Л
- **LEFT JOIN** — соединение, возвращающее все строки из левой таблицы и совпадения из правой.

## Н
- **NULL** — пустое значение, означающее отсутствие данных.

## П
- **Подзапрос** — вложенный запрос внутри другого запроса.

## С
- **SELECT** — оператор выборки данных.
- **СУБД** — система управления базами данных.

## Т
- **Таблица** — структура для хранения данных в реляционной БД.

## У
- **Условие** — проверяемое логическое выражение (да/нет).

## Х
- **HAVING** — фильтр групп после GROUP BY.

## Ч
- **CTE (Common Table Expression)** — временная именованная таблица в запросе.

## Э
- **EXPLAIN** — оператор для анализа плана выполнения запроса.
