# Глоссарий: Архитектура

## API
- **API** — интерфейс взаимодействия между системами.
- **REST API** — архитектурный стиль, использующий HTTP-запросы (GET, POST, PUT, DELETE).

## А
- **Асинхронное взаимодействие** — обмен, при котором отправитель не ждёт ответа.
- **Абстракция** — сокрытие сложности за простым интерфейсом.

## Б
- **Брокер сообщений** — промежуточное звено для асинхронного обмена (Kafka, RabbitMQ).

## Г
- **Геофенсинг** — создание виртуальных полигонов для отслеживания входа/выхода.

## Д
- **Дырявая абстракция** — ситуация, когда детали реализации влияют на окружение через интерфейс.

## И
- **Инкапсуляция** — сокрытие внутренних данных компонента.

## К
- **Контракт API** — формальное описание взаимодействия между системами.

## Л
- **Логический интерфейс** — договор между системой и внешним окружением.

## М
- **Масштабируемость** — способность системы выдерживать рост нагрузки.
- **Микросервис** — архитектурный стиль с независимыми сервисами.

## О
- **Ортогональность** — свойство, при котором изменение в одном компоненте не требует изменений в других.

## П
- **PCI DSS** — стандарт безопасности для обработки платежных данных.
- **Протокол** — правила обмена данными между системами.

## С
- **Синхронное взаимодействие** — обмен, при котором отправитель ждёт ответ.
- **Слабая связанность** — минимальная зависимость компонентов друг от друга.
- **Событие** — произошедший факт, после которого процесс может продолжиться.

## Т
- **Токенизация** — замена конфиденциальных данных на токен.
- **Технический долг** — стоимость доработок из-за неоптимальных решений.

## Ш
- **Шлюз** — посредник между системами.

## Э
- **Эквайринг** — приём и обработка платежей.
