# Sequence: Оформление заказа

Клиент → Приложение: Нажимает "Оформить заказ"
Приложение → Клиент: Показывает форму

Клиент → Приложение: Заполняет данные
Клиент → Приложение: Выбирает способ оплаты

alt Оплата картой
    Клиент → Приложение: Вводит данные карты
    Приложение → Платёжный шлюз: Запрос оплаты
    Платёжный шлюз → Приложение: Успех
else Оплата наличными
    Клиент → Приложение: Выбирает наличные
end

Приложение → БД: Создание заказа
БД → Приложение: OK
Приложение → Клиент: Подтверждение
Приложение → Push-сервис: Уведомление
Push-сервис → Клиент: Push
