# Sequence: Оформление заказа

Клиент → Приложение: Открывает меню
Приложение → БД: GET /api/dishes
БД → Приложение: Список блюд
Приложение → Клиент: Показывает меню

Клиент → Приложение: Добавляет блюда в корзину
Приложение → Клиент: Обновлённая корзина

Клиент → Приложение: Нажимает "Оформить заказ"
Приложение → Клиент: Показывает форму

Клиент → Приложение: Заполняет адрес, телефон
Клиент → Приложение: Выбирает способ оплаты
Клиент → Приложение: Нажимает "Оплатить"

Приложение → Платёжный шлюз: Запрос оплаты
Платёжный шлюз → Приложение: Успех

Приложение → БД: Создание заказа
БД → Приложение: OK

Приложение → Клиент: Подтверждение заказа
Приложение → Курьер: Заказ передан в доставку
Приложение → Клиент: Отслеживание курьера
