# Sequence: Аренда велосипеда

Клиент → Приложение: Открывает карту
Приложение → БД: GET /api/stations
БД → Приложение: Список станций
Приложение → Клиент: Показывает карту

Клиент → Приложение: Выбирает велосипед
Приложение → БД: GET /api/bikes/{id}
БД → Приложение: Данные велосипеда

Клиент → Приложение: Нажимает "Забронировать"
Приложение → БД: POST /api/bookings
БД → Приложение: 201 Created
Приложение → Клиент: Подтверждение брони

Клиент → Приложение: Нажимает "Начать аренду"
Приложение → БД: POST /api/rentals/start
БД → Приложение: 200 OK
Приложение → Платёжный шлюз: Запрос оплаты
Платёжный шлюз → Приложение: Успех
Приложение → Замок: Разблокировка (BLE)
Приложение → Клиент: Аренда активна
