# Sequence: Запись на занятие

Клиент → Приложение: Открывает расписание
Приложение → БД: GET /api/classes
БД → Приложение: Список занятий
Приложение → Клиент: Показывает расписание

Клиент → Приложение: Выбирает занятие
Приложение → БД: GET /api/seats/free
БД → Приложение: Свободные места

Клиент → Приложение: Нажимает "Записаться"
Приложение → БД: POST /api/bookings
БД → Приложение: 201 Created
Приложение → Клиент: Подтверждение

Приложение → Push-сервис: Уведомление
Push-сервис → Клиент: Push
