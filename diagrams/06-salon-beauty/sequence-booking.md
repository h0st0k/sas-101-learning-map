# Sequence: Запись клиента

Клиент → Приложение: Открывает приложение
Приложение → Клиент: Показывает услуги

Клиент → Приложение: Выбирает услугу и мастера
Приложение → БД: GET /api/slots/free
БД → Приложение: Свободные слоты
Приложение → Клиент: Показывает свободные слоты

Клиент → Приложение: Выбирает дату и время
Клиент → Приложение: Вводит имя и телефон
Клиент → Приложение: Нажимает "Записаться"

Приложение → БД: POST /api/bookings
БД → Приложение: 201 Created

Приложение → Клиент: Подтверждение
Приложение → Push-сервис: Отправить уведомление
Push-сервис → Клиент: Push "Вы записаны"

Приложение → Push-сервис: Напоминание за 24 часа
Push-сервис → Клиент: Push "Напоминание о визите"
