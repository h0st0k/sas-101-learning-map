# Use Case: Технопром

## Акторы
- Клиент — подаёт заявку
- Менеджер — обрабатывает заявки, создаёт заказы
- Кладовщик — собирает материалы
- Мастер — выполняет заказ
- Поставщик — предоставляет материалы
- Бухгалтер — контролирует оплаты

## Use Case
| ID | Use Case | Актор | Описание |
|----|----------|-------|----------|
| UC-01 | Подать заявку | Клиент | Клиент подаёт заявку на заказ |
| UC-02 | Обработать заявку | Менеджер | Менеджер обрабатывает заявку |
| UC-03 | Проверить материалы | Система | Проверка наличия материалов |
| UC-04 | Создать заказ | Менеджер | Создание заказа в системе |
| UC-05 | Оплатить заказ | Клиент | Оплата заказа |
| UC-06 | Передать в производство | Менеджер | Передача заказа в производство |
| UC-07 | Собрать материалы | Кладовщик | Сбор материалов для заказа |
| UC-08 | Выполнить заказ | Мастер | Выполнение производственного заказа |
