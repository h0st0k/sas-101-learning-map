# Sequence диаграмма: Создание заказа

## Участники
- Клиент
- Менеджер
- Система
- Склад
- Производство

## Последовательность
1. Клиент → Менеджер: Подаёт заявку
2. Менеджер → Система: Создаёт заказ
3. Система → Склад: Проверяет наличие материалов
4. Склад → Система: Ответ (есть / нет)
5. Система → Менеджер: Статус заказа
6. Менеджер → Клиент: Согласование
7. Клиент → Система: Оплата
8. Система → Производство: Задание
9. Производство → Система: Статус выполнения
