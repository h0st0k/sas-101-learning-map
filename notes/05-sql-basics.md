# Заметки: Основы SQL для аналитика

## Базовые операторы

| Оператор | Что делает |
|----------|------------|
| SELECT | Выборка данных |
| FROM | Из какой таблицы |
| WHERE | Фильтр строк ДО группировки |
| GROUP BY | Группировка |
| HAVING | Фильтр групп ПОСЛЕ группировки |
| ORDER BY | Сортировка |
| LIMIT | Ограничение количества строк |
| JOIN | Соединение таблиц |

## Типы JOIN

| Тип | Что возвращает |
|-----|----------------|
| INNER JOIN | Только совпадающие строки |
| LEFT JOIN | Все из левой + совпадения из правой |
| RIGHT JOIN | Все из правой + совпадения из левой |
| FULL JOIN | Все строки из обеих таблиц |

## Агрегатные функции

| Функция | Что делает |
|---------|------------|
| COUNT(*) | Количество строк |
| SUM() | Сумма |
| AVG() | Среднее |
| MAX() | Максимум |
| MIN() | Минимум |

## Правило GROUP BY
Каждый столбец в SELECT, который не является агрегатной функцией, обязан быть указан в GROUP BY.

## Где искать проблемы

1. Дубликаты телефонов/email
2. Отрицательные суммы
3. NULL в обязательных полях
4. Дата окончания раньше даты начала
5. Активный статус, но срок истёк
6. Записи без клиента или занятия

## Золотое правило
Ноль строк = требование выполняется
Строки есть = проблема
