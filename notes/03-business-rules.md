# Заметки: Бизнес-правила

## Что такое бизнес-правило
Утверждение, которое определяет или ограничивает некоторый аспект бизнеса.

## Классификация

| Тип | Описание | Пример |
|-----|----------|--------|
| Структурное | Определяет структуру данных | Заказ принадлежит клиенту |
| Ограничение | Задаёт допустимые значения | Сумма не может быть отрицательной |
| Процессное | Определяет последовательность | Заказ → Оплата → Доставка |
| Условное | Действия при условии | Если остаток = 0, заказ не создаётся |
| Вычислительное | Формулы расчёта | Цена = кол-во × стоимость |

## Источники бизнес-правил
1. Законы и регуляторы
2. Бизнес-стратегия
3. Интервью со стейкхолдерами
4. Анализ текущих процессов (AS IS)
5. Желаемое состояние (TO BE)

## Формат бизнес-правила
- ID
- Название
- Проект
- Тип
- Приоритет (MUST / SHOULD / COULD)
- Описание
- Бизнес-контекст
- Формулировка
- Источник
- Примеры
- Связанные правила

## Что НЕ входит в бизнес-правила
- Технические детали реализации
- UI/UX (цвет кнопок, расположение)
- Инфраструктурные решения
