# Заметки: Границы системы

## Что входит в границы системы

### Точно в системе
Функции, которые разрабатывает команда

### Точно за границей
Функции, которые остаются за пределами проекта

### Под вопросом
Требуют анализа и согласования

## Типы границ

| Тип | Описание |
|-----|----------|
| Функциональные | Что система делает |
| Пользовательские | Кто взаимодействует |
| Интеграционные | С какими системами общается |
| Данные | Какими данными владеет |
| Географические | Где работает |
| Юридические | Какие законы соблюдает |

## Контекстная диаграмма
Показывает систему в центре и внешние сущности вокруг.

## Анализ "Под вопросом"
Для каждого пункта оценить:
- Риск без интеграции
- Эффект при включении
- Влияние на сроки
- Влияние на бюджет
- Рекомендация

## Принцип
Чётко определённые границы защищают проект от неконтролируемого расширения.
