# Инструменты для SQL

## DBeaver
- **Назначение:** Универсальный клиент для БД
- **Платформа:** Windows, macOS, Linux
- **Особенности:** Бесплатный, поддержка всех СУБД, ER-диаграммы

## DataGrip
- **Назначение:** SQL-клиент для профессионалов
- **Платформа:** Windows, macOS, Linux
- **Особенности:** Платная, мощный автокомплит, отладка

## pgAdmin
- **Назначение:** Клиент для PostgreSQL
- **Платформа:** Веб, Desktop
- **Особенности:** Бесплатный, только PostgreSQL

## SQLite Studio
- **Назначение:** Клиент для SQLite
- **Платформа:** Windows, macOS, Linux
- **Особенности:** Бесплатный, лёгкий

## Когда что использовать
| Инструмент | Когда использовать |
|------------|-------------------|
| DBeaver | Универсальный инструмент |
| DataGrip | Профессиональная работа |
| pgAdmin | Только PostgreSQL |
