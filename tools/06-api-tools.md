# Инструменты для API

## Postman
- **Назначение:** Тестирование API
- **Платформа:** Desktop
- **Особенности:** Бесплатный, коллекции, автоматизация

## Swagger / OpenAPI
- **Назначение:** Документирование API
- **Платформа:** Веб
- **Особенности:** Стандарт, генерация клиентов

## Insomnia
- **Назначение:** Тестирование API
- **Платформа:** Desktop
- **Особенности:** Бесплатный, легче Postman

## Когда что использовать
| Инструмент | Когда использовать |
|------------|-------------------|
| Postman | Тестирование и документация |
| Swagger | Документация API |
| Insomnia | Лёгкое тестирование |
