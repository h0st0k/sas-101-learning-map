# Инструменты для работы с требованиями

## Jira
- **Назначение:** Управление проектами и требованиями
- **Платформа:** Веб
- **Особенности:** Backlog, спринты, User Stories

## Confluence
- **Назначение:** Документирование требований
- **Платформа:** Веб
- **Особенности:** Интеграция с Jira, страницы, база знаний

## Notion
- **Назначение:** Документация и база знаний
- **Платформа:** Веб, Desktop, Mobile
- **Особенности:** Гибкая структура, базы данных

## IBM DOORS
- **Назначение:** Управление требованиями (крупные проекты)
- **Платформа:** Windows
- **Особенности:** Трассировка, аудит

## Когда что использовать
| Инструмент | Когда использовать |
|------------|-------------------|
| Jira + Confluence | Стандартный набор для разработки |
| Notion | Гибкая документация |
| DOORS | Крупные проекты, регуляторные требования |
