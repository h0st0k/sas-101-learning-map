# Инструменты для коммуникации

## Miro
- **Назначение:** Совместная работа, диаграммы
- **Платформа:** Веб
- **Особенности:** Бесплатная версия, доски

## Slack
- **Назначение:** Командная коммуникация
- **Платформа:** Веб, Desktop, Mobile
- **Особенности:** Каналы, интеграции

## Teams
- **Назначение:** Командная коммуникация
- **Платформа:** Веб, Desktop, Mobile
- **Особенности:** Интеграция с Office 365

## Zoom / Google Meet
- **Назначение:** Видеоконференции
- **Платформа:** Веб, Desktop, Mobile
- **Особенности:** Запись встреч

## Когда что использовать
| Инструмент | Когда использовать |
|------------|-------------------|
| Miro | Совместная работа над диаграммами |
| Slack / Teams | Командная коммуникация |
| Zoom / Meet | Встречи с заказчиком |
