# Инструменты для BPMN

## Camunda Modeler
- **Назначение:** Моделирование бизнес-процессов в нотации BPMN
- **Платформа:** Windows, macOS, Linux
- **Особенности:** Бесплатный, поддержка BPMN 2.0, экспорт в XML

## Draw.io / diagrams.net
- **Назначение:** Создание диаграмм (BPMN, UML, ERD)
- **Платформа:** Веб, Desktop
- **Особенности:** Бесплатный, интеграция с Google Drive, GitHub

## Bizagi Modeler
- **Назначение:** Моделирование процессов
- **Платформа:** Windows
- **Особенности:** Бесплатный, Simulation, генерация документации

## Когда что использовать
| Инструмент | Когда использовать |
|------------|-------------------|
| Camunda | Профессиональное BPMN-моделирование |
| Draw.io | Быстрые диаграммы, совместная работа |
| Bizagi | Детальное моделирование с документацией |
