# Инструменты для ERD

## dbdiagram.io
- **Назначение:** Создание диаграмм БД
- **Платформа:** Веб
- **Особенности:** Бесплатный, DSL-язык для описания схем

## Draw.io
- **Назначение:** ER-диаграммы
- **Платформа:** Веб, Desktop
- **Особенности:** Бесплатный, множество шаблонов

## Lucidchart
- **Назначение:** Диаграммы БД
- **Платформа:** Веб
- **Особенности:** Интеграция, совместная работа

## DBeaver
- **Назначение:** Визуализация схемы БД
- **Платформа:** Windows, macOS, Linux
- **Особенности:** Бесплатный, поддержка многих СУБД

## Когда что использовать
| Инструмент | Когда использовать |
|------------|-------------------|
| dbdiagram.io | Быстрое создание схемы |
| Draw.io | Совместная работа |
| DBeaver | Обратный инжиниринг существующей БД |
