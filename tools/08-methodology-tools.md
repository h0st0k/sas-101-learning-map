# Инструменты по методологиям

## Agile / Scrum
- **Jira:** Управление задачами, спринты
- **Trello:** Визуальное управление задачами
- **ClickUp:** Альтернатива Jira

## Waterfall
- **Microsoft Project:** Планирование
- **Excel:** Документирование

## BABOK (Business Analysis Body of Knowledge)
- **Инструменты:** Любые, соответствующие требованиям
- **Главное:** Следование стандартам

## Рекомендация
Для большинства проектов достаточно:
- Jira (задачи)
- Confluence / Notion (документация)
- Draw.io (диаграммы)
- DBeaver (SQL)
- Postman (API)
- Figma (прототипы)
