# Инструменты для прототипирования

## Figma
- **Назначение:** Дизайн и прототипирование интерфейсов
- **Платформа:** Веб, Desktop
- **Особенности:** Совместная работа, библиотеки компонентов

## Balsamiq
- **Назначение:** Низкодетальные прототипы (wireframes)
- **Платформа:** Веб, Desktop
- **Особенности:** Бесплатно для личного использования

## Miro
- **Назначение:** Совместная работа, мозговые штурмы
- **Платформа:** Веб
- **Особенности:** Доска для идей, интеграции

## Когда что использовать
| Инструмент | Когда использовать |
|------------|-------------------|
| Figma | Детальный дизайн |
| Balsamiq | Быстрые прототипы |
| Miro | Brainstorming, flow-диаграммы |
