# Фитнес-клуб "Сила" — аналитика

## Кейс
Система управления фитнес-клубом.

## Аналитические задачи
1. Проверка гипотез по абонементам
2. Поиск аномалий в данных
3. Анализ загрузки залов
4. Отчёты по выручке

## Используемые данные
- Клиенты (clients)
- Абонементы (memberships)
- Записи на занятия (bookings)
- Занятия (classes)
- Платежи (payments)
