# BPMN Шпаргалка

## Основные элементы

| Элемент | Нотация | Что означает |
|---------|---------|--------------|
| Событие | Круг | Что-то происходит |
| Задача | Прямоугольник | Действие |
| Шлюз | Ромб | Ветвление |
| Поток | Стрелка | Переход |

## Типы событий

| Событие | Описание |
|---------|----------|
| Стартовое | Начало процесса |
| Промежуточное | Что-то во время процесса |
| Конечное | Завершение процесса |

## Типы шлюзов

| Шлюз | Описание |
|------|----------|
| XOR | Только один путь |
| OR | Один или несколько путей |
| AND | Все пути одновременно |
