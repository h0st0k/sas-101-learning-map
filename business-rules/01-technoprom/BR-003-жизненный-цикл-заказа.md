# BR-003: Жизненный цикл заказа

## ID
BR-003

## Проект
Технопром

## Тип
Состояние

## Приоритет
MUST

## Описание
Определяет допустимые переходы между состояниями заказа.

## Статусы
| Статус | Описание |
|--------|----------|
| Черновик | Создан, не подтверждён |
| Подтверждён | Ожидает оплаты |
| Оплачен | Оплата получена |
| В работе | Передан в производство |
| Готов | Заказ выполнен |
| Отменён | Отменён клиентом или системой |
| Доставлен | Передан клиенту |

## Переходы
Черновик → Подтверждён (подтверждение клиента)
Черновик → Отменён (отказ)
Подтверждён → Оплачен (оплата)
Подтверждён → Отменён (отказ)
Оплачен → В работе (передача в производство)
Оплачен → Отменён (возврат)
В работе → Готов (выполнение)
Готов → Доставлен (передача клиенту)

## Бизнес-правила
1. Нельзя вернуться из "Оплачен" в "Черновик"
2. Отмена после оплаты требует возврата средств
3. Статус меняется только последовательно
