# Кейс «Блеск» — Салон красоты

## О кейсе
Салон красоты «Блеск»:
- 5 мастеров
- Администратор, директор
- Услуги: стрижка, окрашивание, укладка, маникюр

## Проблемы
- Бумажный журнал (один экземпляр) — риск потери данных
- Обзвон клиентов (~1 час в день)
- 15% неявок
- Ручной подсчёт выручки

## Роли
| Роль | Действия |
|------|----------|
| **Клиент** | Записывается, оплачивает услуги |
| **Администратор** | Управляет расписанием, отмечает посещения |
| **Мастер** | Выполняет услугу |
| **Директор** | Смотрит отчёты по выручке |

## Цель автоматизации
- Онлайн-запись самостоятельно
- Автоматические напоминания (push/SMS)
- Учёт оплат и выручки

## Текущий процесс (AS IS)
1. Клиент звонит администратору
2. Администратор ищет свободное время в журнале
3. Записывает клиента (имя, телефон, услуга, мастер, время)
4. За сутки обзванивает клиентов (напоминание)
5. Клиент приходит → администратор отмечает в журнале
6. Мастер выполняет услугу
7. Администратор считает сумму → клиент платит
8. Администратор записывает оплату в журнал
9. Директор пересчитывает журнал для отчёта

## Целевой процесс (TO BE)
1. Клиент открывает приложение, выбирает услугу и мастера
2. Система показывает календарь со свободными слотами
3. Клиент выбирает дату и время
4. Система создаёт запись и отправляет подтверждение
5. Система за 24 часа отправляет напоминание
6. Клиент приходит → администратор отмечает в системе
7. Мастер выполняет услугу
8. Система считает сумму → клиент оплачивает
9. Система фиксирует оплату и обновляет отчёт
