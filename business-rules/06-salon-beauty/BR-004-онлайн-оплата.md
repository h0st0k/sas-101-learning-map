# BR-004: Онлайн-оплата

## ID
BR-004

## Проект
Блеск

## Тип
Процесс

## Приоритет
SHOULD

## Описание
Клиент оплачивает услугу онлайн через приложение.

## Сценарий
1. Клиент выбирает услугу
2. Нажимает «Оплатить»
3. Система показывает сумму
4. Клиент вводит данные карты
5. Система проверяет платёж
6. Если успешно → создаётся запись об оплате
7. Клиент получает чек
8. Статус записи меняется на «Оплачена»

## Альтернативный сценарий
- Клиент выбирает оплату наличными при посещении
- Система отмечает «Ожидает оплаты»

## Исключения
- Ошибка оплаты → система предлагает другой способ оплаты
- Недостаточно средств → система показывает сообщение

## Бизнес-правила
1. Данные карт не хранятся (PCI DSS)
2. Платёжный шлюз с токенизацией
3. При успешной оплате → автоматическое уведомление администратору

## Связанные правила
