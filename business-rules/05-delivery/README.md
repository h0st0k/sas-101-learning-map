# Кейс «Свежий» — Доставка продуктов

## О кейсе
Сервис доставки продуктов «Свежий»:
- Работает в одном городе
- Собственная сеть складов
- Мобильное приложение для клиентов

## Роли
| Роль | Действия |
|------|----------|
| **Клиент** | Заказывает продукты через мобильное приложение |
| **Сборщик** | Комплектует заказ на складе |
| **Курьер** | Доставляет заказ клиенту |

## Требования
- Клиент выбирает товары из каталога и добавляет в корзину
- Оформление заказа: адрес, телефон, способ оплаты, время доставки
- Оплата: карта онлайн или наличные при получении
- Интервалы доставки: двухчасовые слоты (10–12, 12–14, …, 20–22)
- Клиент может заменить товар при получении
- Push-уведомления: заказ собран → курьер в пути → доставлен

## Проблемы
- Нет слотов в выходные — клиенты жалуются
- Товар заканчивается после оплаты
- Курьеры опаздывают при плохой погоде

## Что за границей
- Работа со складами (внутренний процесс)
- Интеграция с платёжным шлюзом
