# BR-003: Отслеживание курьера на карте

## ID
BR-003

## Проект
Вкусный момент

## Тип
Процесс

## Приоритет
MUST

## Описание
Клиент отслеживает местоположение курьера на карте в реальном времени.

## Сценарий
1. Заказ передан курьеру
2. Система показывает статус «В пути»
3. Клиент открывает карту
4. Система показывает местоположение курьера
5. Клиент видит расчётное время прибытия
6. Курьер отмечает «Доставлен»
7. Система меняет статус на «Доставлен»

## Исключения
- Курьер отклонил GPS → система показывает последний известный адрес
- Интернет отсутствует → данные синхронизируются при восстановлении

## API
GET /api/v1/orders/{id}/tracking
  Response: { "status": "in_progress", "courier_lat": 55.753, "courier_lng": 37.620, "eta": "2026-08-30 19:30:00" }

## Бизнес-правила
1. Трекинг доступен только после передачи заказа курьеру
2. ETA пересчитывается каждые 30 секунд
3. При отклонении от маршрута более чем на 500 метров → уведомление диспетчеру
