# BR-003: Жизненный цикл заказа

## ID
BR-003

## Проект
Чистый пиджак

## Тип
Состояние

## Приоритет
MUST

## Описание
Определяет допустимые переходы между состояниями заказа в химчистке.

## Статусы
| Статус | Описание |
|--------|----------|
| Принят | Заказ создан и принят |
| В работе | Заказ в процессе обработки |
| Готов | Заказ готов к выдаче |
| Можно забирать | Заказ готов, можно забрать |
| Отменён | Заказ отменён |

## Переходы
Принят → В работе (начало обработки)
В работе → Готов (завершение обработки)
Готов → Можно забирать (готов к выдаче)
Принят → Отменён (отмена клиентом)

## Бизнес-правила
1. Статус меняет оператор
2. Клиент видит статус в реальном времени
3. При смене статуса → push-уведомление

- BR-001: Оформление заказа
- BR-002: Отслеживание статуса
