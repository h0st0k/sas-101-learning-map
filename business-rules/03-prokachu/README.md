# Кейс «Прокачу»

Сервис аренды велосипедов:
- 200 велосипедов
- 20 станций
- Telegram-бот (сейчас) → мобильное приложение
- Бюджет: 2 млн руб.
- Срок: 3 месяца

## Роли
| Роль | Действия |
|------|----------|
| Клиент | Ищет, бронирует, арендует, оплачивает |
| Оператор поддержки | Отвечает на обращения, возвращает деньги |
| Администратор | Управляет станциями, статусами |
| Руководитель | Смотрит отчёты |

## Проблемы (бот)
- 8 шагов для аренды
- Нет карты
- Нельзя забронировать заранее
- Забывают завершить аренду
- Нет истории

## Требования
- Карта со станциями
- Бронирование на 15 минут
- Push-уведомления
- Автозавершение по геолокации
- История поездок
