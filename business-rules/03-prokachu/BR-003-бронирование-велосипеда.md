# BR-003: Бронирование велосипеда

## ID
BR-003

## Проект
Прокачу

## Тип
Процесс

## Приоритет
MUST

## Описание
Клиент бронирует велосипед на 15 минут через мобильное приложение.

## Сценарий
1. Клиент открывает карту станций
2. Выбирает свободный велосипед
3. Нажимает «Забронировать»
4. Система резервирует велосипед на 15 минут
5. Запускается таймер
6. Клиент получает push-уведомление

## Альтернативный сценарий
- Клиент не пришёл → бронь отменяется через 15 минут
- Клиент передумал → нажимает «Отменить бронь»

## Исключения
- Велосипед уже забронирован → система показывает «Занят»
- Нет свободных велосипедов → система предлагает другую станцию

## Бизнес-правила
1. Бронирование — на 15 минут
2. За 3 минуты до окончания → push-уведомление
3. Автоотмена через 15 минут
4. Нельзя забронировать, если есть активная аренда

## API
POST /api/v1/bookings
  Request: { "bike_id": 123, "station_id": 5 }
  Response: { "booking_id": 789, "expires_at": "2026-08-30 15:15:00" }

DELETE /api/v1/bookings/{id}
