# BR-004: Отчёт о поломке

## ID
BR-004

## Проект
Прокачу

## Тип
Процесс

## Приоритет
SHOULD

## Описание
Клиент отправляет отчёт о поломке велосипеда.

## Сценарий
1. Клиент нажимает «Сообщить о поломке»
2. Выбирает компонент из списка:
   - Тормозная система
   - Колесо
   - Цепь/Педали
   - Электронный замок
3. Прикрепляет фото (до 5 МБ)
4. Нажимает «Отправить»
5. Система создаёт заявку
6. Оператор получает уведомление

## Бизнес-правила
1. Обязательный выбор компонента
2. Фото до 5 МБ
3. Заявка отправляется оператору
