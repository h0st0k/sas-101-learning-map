# Бизнес-правило: Аренда велосипеда

## Метаданные
| Поле | Значение |
|------|----------|
| **ID** | BR-PR-001 |
| **Версия** | 1.0 |
| **Дата создания** | 2026-08-30 |
| **Автор** | |
| **Кейс** | Прокачу |

## Описание
Клиент арендует велосипед

## Триггер
Клиент нажал «Арендовать»

## Предусловия
- Клиент авторизован
- На счету ≥ 500 руб. (депозит)
- Велосипед свободен
- Время: 06:00 – 23:00

## Основной поток
| Шаг | Действие | Кто выполняет |
|-----|----------|---------------|
| 1 | Открывает карту | Клиент |
| 2 | Выбирает станцию и велосипед | Клиент |
| 3 | Проверяет доступность | Система |
| 4 | Нажимает «Арендовать» | Клиент |
| 5 | Холдирует депозит 500 руб. | Система |
| 6 | Открывает замок (BLE) | Система |
| 7 | Статус → «Арендован» | Система |
| 8 | Запускает таймер аренды | Система |
| 9 | Отправляет push | Система |

## Исключительные потоки
### Е1. Недостаточно средств
- **Привязка:** Шаг 5
- **Реакция:** «Пополните баланс»
- **Результат:** Цель НЕ достигнута

### Е2. Велосипед занят
- **Привязка:** Шаг 3
- **Реакция:** «Велосипед заняли. Выберите другой»
- **Результат:** Цель НЕ достигнута

## Постусловия
- Велосипед заблокирован
- Таймер запущен
- Депозит удержан

## Бизнес-правила
- Работа: 06:00 – 23:00
- Зона: МКАД
- Депозит: 500 руб.
- Тариф: 150 руб/час

## Связанные требования
- FR-001: Карта со свободными велосипедами
- FR-002: Открытие замка по BLE
