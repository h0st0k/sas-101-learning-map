# BR-004: Жизненный цикл абонемента

## ID
BR-004

## Проект
Фитнес-клуб "Сила"

## Тип
Состояние

## Приоритет
MUST

## Описание
Определяет допустимые переходы между состояниями абонемента клиента.

## Статусы
| Статус | Описание |
|--------|----------|
| ЧЕРНОВИК | Счёт сформирован, ждёт оплату |
| ОПЛАЧЕНА | Деньги поступили, абонемент активен |
| ЗАМОРОЖЕНА | Пауза (отпуск/болезнь). Срок не идёт |
| ИСТЕКЛА | Срок действия вышел |
| ОТМЕНЕНА | Заказ отменён клиентом |

## Переходы
ЧЕРНОВИК → ОПЛАЧЕНА (оплата)
ЧЕРНОВИК → ОТМЕНЕНА (отказ)
ОПЛАЧЕНА → ЗАМОРОЖЕНА (заморозка)
ОПЛАЧЕНА → ИСТЕКЛА (истек срок)
ОПЛАЧЕНА → ОТМЕНЕНА (отмена)
ЗАМОРОЖЕНА → ОПЛАЧЕНА (возврат с паузы)
ЗАМОРОЖЕНА → ОПЛАЧЕНА (истек период заморозки)

## Бизнес-правила
1. Заморозка возможна на срок до 30 дней
2. Автоматическая активация после истечения периода заморозки
3. Абонемент не может быть продлён после истечения срока
