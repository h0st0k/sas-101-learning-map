# Кейс «Фитнес-клуб Сила»

Сеть фитнес-клубов:
- 3 клуба в городе
- Бассейн, тренажёрный зал, групповые занятия
- Бюджет: 3 млн руб.
- Срок: 4 месяца
- Платформа: iOS + Android

## Роли
| Роль | Действия |
|------|----------|
| Клиент | Покупает абонемент, записывается, бронирует |
| Администратор | Управляет расписанием, отмечает посещения |
| Тренер | Видит расписание и список клиентов |
| Директор | Смотрит отчёты по выручке и загрузке |

## Что в системе
- Покупка абонемента (месяц, 3, год)
- Запись на групповые занятия
- Бронирование дорожек в бассейне
- Push-уведомления
- Управление расписанием

## Под вопросом
- Интеграция с CRM, 1С
- Автоответы в соцсетях

## За границей
- Продажа товаров
- Онлайн-тренировки
- Интеграция с фитнес-браслетами
