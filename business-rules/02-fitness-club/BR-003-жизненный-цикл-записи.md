# BR-003: Жизненный цикл записи

## ID
BR-003

## Проект
Фитнес-клуб "Сила"

## Тип
Состояние

## Приоритет
MUST

## Описание
Определяет допустимые переходы между состояниями записи на занятие.

## Статусы
| Статус | Описание |
|--------|----------|
| ЧЕРНОВИК | Запись создана, не подтверждена |
| АКТИВНАЯ | Подтверждена |
| ОПЛАЧЕНА | Оплачена |
| ЗАВЕРШЕНА | Клиент посетил занятие |
| ОТМЕНЕНА | Отменена клиентом или системой |
| НЕЯВКА | Клиент не пришёл |

## Переходы
ЧЕРНОВИК → АКТИВНАЯ (подтверждение записи)
ЧЕРНОВИК → ОТМЕНЕНА (отказ)
АКТИВНАЯ → ОПЛАЧЕНА (оплата)
АКТИВНАЯ → ЗАВЕРШЕНА (посещение)
АКТИВНАЯ → ОТМЕНЕНА (отмена до 1 часа)
АКТИВНАЯ → НЕЯВКА (не пришёл)
ОПЛАЧЕНА → ЗАВЕРШЕНА (посещение)
ОПЛАЧЕНА → ОТМЕНЕНА (отмена со штрафом)
ОПЛАЧЕНА → НЕЯВКА (не пришёл)

## Бизнес-правила
1. Нельзя вернуться из "ОПЛАЧЕНА" в "АКТИВНАЯ"
2. Отмена возможна только до 1 часа до занятия
3. При отмене оплаченной записи требуется возврат средств

## Связанные правила
- BR-001: Запись на занятие
- BR-002: Отмена записи
