## 🧠 Основные разделы

### 1. Бизнес-правила
Формализованные правила для каждого учебного кейса с использованием шаблона:
- Метаданные
- Триггер и предусловия
- Основной поток (Happy Path)
- Альтернативные и исключительные потоки
- Постусловия

### 2. Моделирование процессов
- AS-IS / TO-BE модели
- BPMN-диаграммы
- Контекстные диаграммы
- Точки автоматизации

### 3. Требования и сценарии
- User Stories + Acceptance Criteria
- Use Cases
- SRS (Software Requirements Specification)
- MoSCoW-приоритизация

### 4. Работа с данными
- SQL-запросы
- Проверка требований данными
- Модели данных (ERD)
